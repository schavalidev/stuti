# Reader-field source audit — 2026-09-12

**Standing rule (user, 2026-09-12): the reader must never be shown the source information.**
The rule and the field lists are in the repo-root `CLAUDE.md`, and `bin/reader_view.py` enforces
them by allow-list — the withheld fields (`Source / recension`, `Recension note` and the rest)
cannot reach an app that uses it.

This file lists the other half of the problem: **sourcing written into the fields a reader does
see.** Those cannot be hidden by field, because the field itself is reader-facing; the sentence
has to be rewritten.

**What a fix looks like, in each field:**

- `Author` — state the attribution, not how it was established. "Traditional; the colophon names no
  composer" instead of "unattributed in the base recension; sanskritdocuments catalogues it as…".
- `Verse count` — the count and what the units are. Which edition numbers them that way belongs in
  the `Recension note`.
- `Sections` — the section names. Not which print leaves a block unnumbered.
- `Blurb` — what the text is and what it says. Not which press published it.
