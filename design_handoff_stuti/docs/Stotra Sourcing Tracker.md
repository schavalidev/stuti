# Stotra Sourcing Tracker

Last updated: 2026-08-29. Tracks sourcing progress against `stotra-index-data.js`'s
140-title master index (8 deities). This is a living document — update a row's
**Status** the moment its situation changes (verified → written, unverified →
resolved, etc.) and refresh the summary table below at the same time.

## Status legend

- ✅ **Written** — full text is live in a `stuti-text-*.js` file
- 🔍 **Verified** — real source found and confirmed (VERIFIED per the project's
  no-memory-reconstruction rule); ready to write, just not written yet
- ⚠️ **Unverified** — no confirmed source at an approved site, OR the exact title
  doesn't match anything findable, OR there's a decision (which recension? which
  of two same-named texts?) that has to be made before sourcing can even start
- 🈺 **Non-Sanskrit** — flag added to Verified/Unverified rows whose primary
  textual tradition is Tamil/Hindi/Telugu/Marathi, not Sanskrit — needs
  deliberate transliteration handling, not Sanskrit-guessing
- 📜 **Nāmāvalī** — flag added to rows that are a name-list (aṣṭottaraśatanāma /
  sahasranāma litany) rather than a normal verse stotra — needs the list/grid
  template, not the verse-block template
