Reading this board

Every frame holds the same screen, so the only variable is type. The two diacritic strips near the bottom of each phone are the test that matters: the first is set in the display face, the second in the UI face. Any letter that jumps in weight or shape is falling back to Georgia or the system sans, not being drawn by the font.

The six frames on the top row set all twenty-two diacritics the corpus actually uses — measured, not assumed, including ṁ, which appears 147 times and is the character most Latin fonts omit. The three on the bottom row each have a gap, named in their caption; they are here because two of them are faces you already asked about.

The UI face is what sets transliteration, glosses, limb values and every screen label, so its coverage matters more than the display face's. A display face with gaps is survivable if titles avoid the missing letters — but Prātaḥ Sandhyā already contains one.
