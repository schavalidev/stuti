Four ways to set the speed

Each control is live — tap, drag, and feel it. They all drive the same playback rate (which then scales per-name by length). The question is which gesture fits chanting best.

Current app uses a 3-chip toggle capped at 1.5×. All options below extend the range for advanced readers.

AExtended presets

The current segmented toggle, just with more named tempos up to 3×. Tappable mid-recitation, repeatable, no fiddly aim. Familiar — it's what's there now.

My recommendation

For chanting, C (snap slider) now does exactly what you asked — many speeds on the drag, −/+ for custom tempos like 1.40× and 1.45×, and the standard speeds as quick chips below so a reader can always tap back to "their" speed. A (extended presets) is the safest, smallest change if you'd rather keep the current feel. Tell me A, B, C, or D (or a mix) and I'll roll it into all three recite bars.
